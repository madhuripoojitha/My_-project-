# Weather Prediction - Entity Relationship Diagram

## Overview
This document describes the Entity Relationship Diagram (ERD) for a Weather Prediction system.

## Entities and Relationships

### 1. User
- **Attributes**: id, name, email
- **Primary Key**: id
- **Relationship**: submits (1:N) with Weather Data

### 2. Weather Data
- **Attributes**: id, user_id, temperature, humidity
- **Primary Key**: id
- **Foreign Key**: user_id (references User)
- **Relationship**: generates (1:N) with Prediction

### 3. Prediction
- **Attributes**: id, weather_data_id, model_id, result
- **Primary Key**: id
- **Foreign Keys**: weather_data_id, model_id
- **Relationships**: 
  - Generated by (1:N) Weather Data
  - Produces (N:1) Machine Learning Model

### 4. Machine Learning Model
- **Attributes**: id, name, version
- **Primary Key**: id
- **Relationship**: produced by (N) Predictions

## Relationship Cardinality

- **1:N** = One to Many
- **1:1** = One to One
- **N:N** = Many to Many

## Diagram Description

```
┌─────────────────────────────────────────────────────────────────┐
│              User (1) ─submits─→ Weather Data (N)               │
│                                           │                     │
│                                        generates                 │
│                                           │                     │
│                                           ↓ (1:N)               │
│                            Prediction (N) ─produces→ ML Model  │
└─────────────────────────────────────────────────────────────────┘
```

The system allows multiple users to submit weather data, which is then used to generate weather predictions using machine learning models.
